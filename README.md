# Wi-Fi Password Viewer (Windows)

A simple and lightweight Python script designed to help you recover and view all the Wi-Fi passwords saved on your Windows computer.

## Features

- Automatically fetches all previously connected Wi-Fi profiles.
- Displays the Wi-Fi name (SSID) and its corresponding password in a clean format.
- Uses the built-in Windows `netsh` command to retrieve credentials safely.

## How to Use

1. Clone this repository or download the script.
2. Open your terminal or command prompt (CMD).
3. Run the script using Python:
   ```bash
   python wifi_viewer.py
   ```
